# Llama API Gateway

FastAPI gateway for Llama 3.2 inference. **Render hosts the API gateway; Cloudflare Workers AI runs the model** in the free-tier configuration. This is not model-weight hosting on Render.

## Features
- OpenAI-compatible `POST /v1/chat/completions`
- `GET /v1/models`, `/health`, and `/docs`
- Bearer API-key authentication
- Basic in-memory per-IP rate limiting
- Provider abstraction: Cloudflare Workers AI now, Ollama later
- Non-streaming chat completions

## Deploy on Render Free
1. Create a Cloudflare account and enable Workers AI.
2. Find your Cloudflare Account ID and create an API token with Workers AI permissions.
3. In Render, choose **New → Blueprint** and connect this repository.
4. Render reads `render.yaml` and creates a Free web service.
5. Add `CLOUDFLARE_ACCOUNT_ID` and `CLOUDFLARE_API_TOKEN` as secret environment variables.
6. Render generates `APP_API_KEY`; copy it from the service Environment page. Never put it in frontend code or commit it.
7. After deployment, test `/health` and then the chat endpoint below.

Cloudflare Workers AI has usage quotas and usage beyond included allowances may be billable. Check current pricing and limits before exposing the API publicly: https://developers.cloudflare.com/workers-ai/platform/pricing/ . Render Free services sleep when idle and may take time to wake up.

## Test

Health (no key required):

```bash
curl https://YOUR-SERVICE.onrender.com/health
```

Chat:

```bash
curl https://YOUR-SERVICE.onrender.com/v1/chat/completions \\
  -H "Authorization: Bearer YOUR_APP_API_KEY" \\
  -H "Content-Type: application/json" \\
  -d '{"model":"llama-3.2-3b-instruct","messages":[{"role":"user","content":"Explain REST APIs simply"}],"max_tokens":200,"stream":false}'
```

Swagger UI: `https://YOUR-SERVICE.onrender.com/docs`.

## OpenAI Python SDK

```bash
pip install openai
```

```python
import os
from openai import OpenAI

client = OpenAI(
    base_url="https://YOUR-SERVICE.onrender.com/v1",
    api_key=os.environ["LLAMA_GATEWAY_API_KEY"],
)
response = client.chat.completions.create(
    model="llama-3.2-3b-instruct",
    messages=[{"role": "user", "content": "Hello!"}],
    max_tokens=200,
)
print(response.choices[0].message.content)
```

## Switch to Ollama later

Set these variables on a host that can reach your Ollama instance:

```env
INFERENCE_PROVIDER=ollama
OLLAMA_BASE_URL=http://YOUR_OLLAMA_HOST:11434
OLLAMA_MODEL=llama3.2:1b
```

Do not expose Ollama's port 11434 publicly without network restrictions and authentication. Render Free cannot reliably host the model weights itself; this switch requires an independently hosted Ollama server reachable by the gateway.

## Environment variables

- `APP_API_KEY`: gateway bearer key (generated by Render Blueprint).
- `INFERENCE_PROVIDER`: `cloudflare` or `ollama`.
- `CLOUDFLARE_ACCOUNT_ID`, `CLOUDFLARE_API_TOKEN`: Cloudflare credentials.
- `CLOUDFLARE_MODEL`: defaults to `@cf/meta/llama-3.2-3b-instruct`.
- `MAX_REQUESTS_PER_MINUTE`: per-process IP request limit, default 20.
- `MAX_OUTPUT_TOKENS`: maximum response tokens, default 1024.

The included rate limiter is a basic single-process guard, not distributed abuse protection. Add stronger quotas/monitoring before production use.
